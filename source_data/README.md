# Figure and table source data

This directory is the canonical source-data location.

- `figures/core/`: numerical data used by Figures 2, 5, 6, and 8, plus cross-fitted, diversity, composition-control, and mechanism analyses used across the main figures.
- `figures/figure7/`: panel A–D tables and the combined Figure 7 workbook.
- `figures/ten_seed_audit/`: ten-seed sensitivity, classification-metric, constructed-control, recovery-simulation, and execution-audit data.
- `tables/main/`: machine-readable Tables 1–4.
- `tables/primary_cross_fitted_effects.csv`: endpoint-level cross-fitted effects used for manuscript direction checks.

Figure 1 is a conceptual workflow schematic and has no numerical source table. Final rendered figures are stored once in `results/final/figures/`.
