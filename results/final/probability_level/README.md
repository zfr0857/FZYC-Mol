# Probability-level classification outputs

This directory contains the retained molecule-level probability/risk exports. The ten-seed classification audit retains candidate/fold/seed-level ROC-AUC, PR-AUC, Brier, threshold, and recall outputs under `results/final/ten_seed_audit/run_records/classification_metric_rerun/` and `source_data/figures/ten_seed_audit/classification_metric_selection_units.csv`; it does not retain a second redundant molecule-level probability matrix for every candidate.

No probabilities, labels, candidate identities, thresholds, seed assignments, or negative results were reconstructed or altered during repository consolidation.
