# Probability-level classification outputs

The retained molecule-level probability/risk exports are mirrored from
`results/reviewer_core_20260624/`. The Paper 43 ten-seed classification rerun
retained candidate/fold/seed-level ROC-AUC, PR-AUC, Brier, threshold and recall
outputs under `run_records/classification_metric_rerun/` and
`source_data/classification_metric_selection_units.csv`; it did not retain a
second redundant molecule-level probability matrix for every candidate.

No probabilities, labels, candidate identities, thresholds, seed assignments
or negative results were reconstructed or altered for this release.
